# Wireframe: Dorminator

เอกสารนี้แสดงโครงหน้าจอหลักของระบบจัดการหอพัก Dorminator ออกแบบแบบ Mobile First โดยใช้จุดเปลี่ยนการแสดงผล 2 ขนาดหลัก คือ 768px (แท็บเล็ต) และ 992px (เดสก์ท็อป)

## แผนผังหน้าเว็บ (Site Map)

```text
บุคคลทั่วไป                 ผู้เช่า (Tenant)              ผู้ดูแล (Admin)
─────────────              ────────────────            ────────────────
index.html                 tenant/dashboard.html       admin/dashboard.html
 └─ room-detail.html       tenant/billing.html         admin/billing.html
login.html                 tenant/maintenance.html      └─ admin/create_bill.html
register.html              tenant/profile.html         admin/promotions.html
                           tenant/chat.html            admin/users.html
                                                       admin/maintenance.html
                                                       admin/chat.html
```

## 1. หน้าแรก (index.html)

แถบเมนูแสดงเป็นปุ่มแฮมเบอร์เกอร์บนมือถือ และแสดงลิงก์เต็มเมื่อจอกว้างตั้งแต่ 768px

```text
มือถือ (< 768px)              เดสก์ท็อป (>= 768px)
┌───────────────────┐        ┌──────────────────────────────────────────┐
│ Dorminator     ☰  │        │ Dorminator         หน้าแรก  ดูห้องว่าง  [เข้าสู่ระบบ] │
├───────────────────┤        ├──────────────────────────────────────────┤
│   HERO            │        │                  HERO                    │
│   ยินดีต้อนรับ      │        │              ยินดีต้อนรับ                  │
│   [มีห้องว่าง N ห้อง]│        │            [มีห้องว่าง N ห้อง]              │
├───────────────────┤        ├──────────────────────────────────────────┤
│ ข้อมูลหอพัก (แท็บ)   │        │  ข้อมูลหอพัก: Highlight | แผนที่ | สิ่งอำนวยฯ   │
├───────────────────┤        ├──────────────────────────────────────────┤
│ ตารางสรุปประเภทห้อง  │        │  ตารางสรุปประเภทห้อง ราคา และห้องว่าง         │
├───────────────────┤        ├──────────────┬───────────────────────────┤
│ ┌───────────────┐ │        │  รูปห้อง       │ Size S                    │
│ │ รูปห้อง < >     │ │        │  < >         │ คำอธิบาย  ราคา  [ว่าง N ห้อง] │
│ ├───────────────┤ │        │              │ [ชมรายละเอียด]             │
│ │ Size S ราคา   │ │        ├──────────────┴───────────────────────────┤
│ │ [ชมรายละเอียด] │ │        │  Footer                                  │
│ └───────────────┘ │        └──────────────────────────────────────────┘
```
