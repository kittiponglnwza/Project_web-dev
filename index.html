MyDorm Apartment (KMUTNB)

มายดอร์ม อพาร์ทเมนต์ - ใกล้ ม.พระจอมเกล้าพระนครเหนือ

รีวิวจาก 45 คน

MyDorm Apartment โครงการตั้งอยู่ทำเลทอง ใกล้คณะวิทยาศาสตร์ประยุกต์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (มจพ.) เพียงระยะเดิน 5 นาที หน้าโครงการมีร้านสะดวกซื้อ 7-11, ร้านอาหาร, และคาเฟ่มากมาย ตอบโจทย์ไลฟ์สไตล์นักศึกษาและวัยทำงานที่ต้องการความสะดวกสบายและความปลอดภัยขั้นสูงสุด

📍 สถานที่สำคัญใกล้เคียง

  • ม.เทคโนโลยีพระจอมเกล้าพระนครเหนือ (มจพ.) : 300 ม.
  • คณะวิทยาศาสตร์ประยุกต์ มจพ. : 350 ม.
  • ร้านสะดวกซื้อ 7-11 / ร้านอาหาร : 50 ม.
  • ตลาดนัด / ศูนย์อาหาร : 150 ม.
  • MRT สายสีม่วง (สถานีวงศ์สว่าง) : 2.5 กม.
  • โรงพยาบาลเกษมราษฎร์ ประชาชื่น : 3.2 กม.
  • Gateway บางซื่อ : 4.5 กม.
